# Doom Emacs Configuration

Personal Doom Emacs setup tailored for Rust, systems programming, and high-performance development.

## Structure
- `config.el` - Core Doom Emacs custom configuration, UI tweaks, keybindings, and LSP/Eglot setups
- `init.el` - Doom module declarations
- `packages.el` - Custom package declarations
- `snippets/` - Custom snippets (Rust, C/C++, TypeScript, C#, Python)
- `themes/` - Custom Emacs themes (Doom Neovim Dark theme)

## Installation
Clone into `~/.config/doom`:
```bash
git clone https://github.com/Sruhvx-jpg/doom-emacs-config.git ~/.config/doom
doom sync
```
